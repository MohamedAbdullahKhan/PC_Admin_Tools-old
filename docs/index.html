What the tool does

    
Everything below is in the demo above.

    

      
90 tasks, 9 categories
Cleanup, Disk, Performance, Windows Health, Network, Power Recycle, Remote Tools, Admin Consoles and Network Push. Tick any mix; they run in a fixed, safe order.

      
Typed, validated inputs
IPs, masks (or CIDR), computer names, adapter names, service names, drive letters, UNC paths, user accounts and VSS sizes are checked before anything is sent. Try a bad IP in Set Static IP.

      
Confirm before danger
Anything that restarts, resets, deletes or can cut the connection is flagged with ! and needs a confirmation.

      
Live colour-coded log
Every output line is classified as success, warning or error by keyword, with progress and a task counter - exactly like the real log pane.

      
Network changes without drama
Inline tasks (Set Static IP, DHCP, adapter restarts) expect the connection to drop, never repeat the change, reconnect on the old host and the new IP, then print the new status.

      
Network Push + Ping Host
Push-only tasks send the command and report "Static IP set cmd pushed to the target machine" without waiting. Ping Host then watches the old IP, the new IP and what DNS says until you press Stop.

      
Long jobs survive disconnects
DISM RestoreHealth, component cleanup and CHKDSK run as a one-shot SYSTEM scheduled task on the target, with periodic "still running" lines.

      
Reboot-aware
Rename, force restart and soft-recycle tasks treat the dropped connection as expected and skip the remaining tasks instead of failing noisily.

      
Admin Consoles
One-click launchers for Computer Management, Disk Management, Services, Event Viewer, Firewall, a remote PowerShell/cmd and Remote Desktop, pointed at the target.

Three editions, one task library

    
All three run PowerShell on the remote PC over WinRM and share the same 90 tasks. Pick the one that suits how you work.

    

      
PowerShell GUI
A native Windows form. No Python needed - just run it.
PC_Admin_Tool_PowerShell_Edition/PCAdminTool.ps1Run-AdminTool.bat

      
Web-Service
A Flask service on port 3039. Anyone on the allowed subnet opens it in a browser - the interface you just used. Runs as a Windows service or on Linux.

Python Tk GUI
A desktop window written in Python/Tkinter.

Run the real tool

    
Step by step, no experience needed. Windows 10/11 or Server on the admin PC; the target PCs need WinRM enabled.

    
    
      
  1. Download. Open the GitHub repository, press the green Code button, choose Download ZIP, then right-click the ZIP and Extract All.
    2. 
      
  2. Pick an edition folder (see above). Easiest for beginners: the PowerShell GUI edition.
    3. 
      
  3. PowerShell GUI: double-click Run-AdminTool.bat. Python Tk GUI: install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then double-click install_and_run.bat. Web-Service: install Python the same way, then double-click install_and_run.bat (Windows) or run ./install_and_run.sh (Linux), and open http://localhost:3039.
    4. 
      
  4. Allow remote management on a target PC (once, in an administrator PowerShell on that PC): 
    Enable-PSRemoting -Force
    5. 
      
  5. Connect. Type the target's name or IP, a username like DOMAIN\admin and its password, press Test Connection, tick tasks and press RUN SELECTED TASKS.
    6. 
    

    
Each edition folder has its own README with the exact details for that version.

  






  

    
What this demo is - and is not

    

      Simulated. Real WinRM cannot be done from a web page, so this site never touches a real PC. Output numbers are random; output wording mirrors the real tool. Admin Console tasks only describe what they would launch, because a browser cannot open desktop windows. Real-world timing (SFC, DISM, CHKDSK) is sped up using a virtual clock. The real tool's behaviour on your network can differ - always test on a non-critical PC first.
